На сайт

Стайлгайд: шутовские маргиналии

Рабочая страница: палитра, шрифты, детали интерфейса и полный список картинок, которые ещё предстоит нарисовать. В поиске не индексируется.

Идея

Сайт — расписная рукопись. Каждая страница открывается сценой-миниатюрой из шести слоёв (небо, облака, дальний план, средний план, земля, передний план), по которой ходят нелепые зверьки. Ниже — пергаментный лист с текстом: толстый чернильный контур, плоские «темперные» заливки, цветная смещённая тень вместо размытой, всё слегка криво, как нарисовано рукой.

  • Контур — всегда 2px цвета чернил. Тень — плоская, 5px 5px 0, цветная. Никаких размытий и градиентов-переливов.
  • Яркие пигменты живут в сценах, кнопках, ярлыках и тенях. Текст — только чернила на пергаменте.
  • Лёгкий наклон (до 2,5°) — у «прикреплённых» вещей: фотографий, ярлыков с датой, записок. Текстовые блоки стоят ровно.
  • У каждой главы свой цвет и своё время суток — по нему глава узнаётся во флажках, карточках и тенях.

    Правила для картинок

    • Манера. Книжная миниатюра XIII–XV веков, гуашь/темпера по пергаменту: плоские заливки, тёмный контур, чуть неровная рука, без перспективы и без мягких теней. Звери с человеческими занятиями, серьёзные лица при нелепых делах.
    • Цвет. Только пигменты из палитры выше; у каждой сцены свои пять тонов.
    • Слои фона. PNG шириной 2400 px, бесшовно стыкуются по горизонтали, всё выше силуэта прозрачное (небо — непрозрачное). Высоты — в таблице.
    • Спрайты. PNG с прозрачностью: одна горизонтальная лента из квадратных кадров 256×256. Персонаж смотрит вправо, ноги стоят на нижнем крае кадра, размер и положение в кадре не меняются от кадра к кадру.
    • Миниатюры карточек. 480×360, непрозрачные.
    • Куда класть. В assets/art/ под именем из таблицы — картинка появится на сайте сама. Пока файла нет, на его месте пунктирная заглушка; чтобы спрятать заглушки перед публикацией, в scenes.js поставьте SHOW_SLOTS = false.
